# Teacher Notes

## How To Use

Ask learners to predict which angle gives the longest range before moving the
slider. Then compare their prediction with the graph.

## Questions To Ask

- What changes when the speed doubles?
- Why does a 45 degree angle maximize range in this simplified model?
- What real-world effects are missing?

## Accessibility Notes

The graph uses color and position. The readout cards repeat the numerical
values so the result is not color-only.
