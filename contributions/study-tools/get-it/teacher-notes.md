# Teacher Notes

## How To Use

Use this as a reference for discussion, not as a copied dependency. Ask what a
student needs when a document is hard to understand:

- concept tags;
- visuals;
- practice tools;
- a map of what they understand.

## Questions To Ask

- Which part of this workflow belongs in Paideia's simple gallery?
- Which parts are too complex for the current repository?
- What can be represented as one small contribution package?

## Accessibility Notes

This package links to an external project. Review the external app separately
before recommending it as a learner-facing tool.
