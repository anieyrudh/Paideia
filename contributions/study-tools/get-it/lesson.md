# Get It

## Why It Is Included

Get It is a useful reference for Paideia because it shows a clear product idea:
read a source document, identify concepts, and show the student visuals and
study tools around those concepts.

## What Paideia Can Learn From It

- Start from material the learner already has.
- Show concepts visually instead of only summarizing text.
- Keep study work connected to the source document.
- Use a knowledge map to show what the learner understands.

## How To Use This Package

This is a reference package, not imported code. Review the linked repository and
borrow product ideas only when the license and attribution are handled.
