# Transfer Problem: Velocity Selector Entry

## Prompt

A positive ion enters a uniform magnetic field directed into the page. It travels to the right at \(2.5 \times 10^3\ \text{m s}^{-1}\) and has charge \(3.0\ \mu\text{C}\). The field strength is \(0.060\ \text{T}\).

1. Calculate the magnetic force magnitude.
2. State the direction of the force.
3. Explain what changes if the ion is negative but has the same speed and charge magnitude.

## Worked Solution

Convert charge first:

\[
q = 3.0\ \mu\text{C} = 3.0 \times 10^{-6}\ \text{C}
\]

The velocity is perpendicular to the field, so \(\sin 90^\circ = 1\):

\[
F = |q|vB\sin\theta
  = (3.0 \times 10^{-6})(2.5 \times 10^3)(0.060)(1)
  = 4.5 \times 10^{-4}\ \text{N}
\]

For a positive ion moving right with the field into the page, Fleming's left-hand rule gives force up the page. For a negative ion, the magnitude is unchanged but the direction reverses, so the force is down the page.

## Same-Concept Check

This is still magnetic force: identify the moving charge, use the perpendicular component of velocity, calculate \(F = |q|vB\sin\theta\), then handle direction using charge sign.
