# Resolving Vectors

This container is the first downstream simulation after Scalars and Vectors.
It turns one vector into perpendicular components and makes the formula visible
inside the simulation.

## Surfaces

- `container.yaml` declares the sim-worthy v2 container.
- `concept-card.md` gives the first-principles explanation.
- `simulation/` hosts the prediction-gated component-resolution sim.
- `concept-map/` connects units, scalars/vectors, and later force/kinematics topics.
- `problem-solving/` records the component-resolution algorithm and transfer task.
- `embed/` exposes the standard host API.
