# Transfer Problem: Ramp Force Components

A `12 N` force pulls a trolley at `25 degrees` above the horizontal.

## Expected Reasoning

The horizontal component is:

```text
x = 12 cos 25 degrees = 10.9 N
```

The vertical component is:

```text
y = 12 sin 25 degrees = 5.1 N
```

The horizontal component changes the trolley's horizontal motion. The vertical
component changes the normal contact balance, depending on the rest of the
problem setup.

## Rubric

- Draws or names the angle reference.
- Uses cosine for the horizontal component because the angle is from the horizontal.
- Uses sine for the vertical component.
- Keeps `N` as the unit for both components.
- Explains that components replace the original vector for axis-based analysis.
