# Transfer Problem: Unit Consistency Check

A student writes a measured acceleration as `9.8 m s^-1`. Decide whether the
unit is dimensionally consistent with acceleration, correct it if needed, and
explain which base units are involved.

## Worked Solution

1. The physical quantity is acceleration: change in velocity per unit time.
2. Velocity has unit `m s^-1`.
3. Dividing velocity by time gives `(m s^-1) / s = m s^-2`.
4. The student's unit `m s^-1` has dimension `L T^-1`, which is speed, not acceleration.
5. The corrected acceleration record is `9.8 m s^-2` if the numerical value is intended to be the acceleration magnitude.

## Rubric

- Identifies acceleration as a derived quantity from velocity per time.
- Expands the unit to SI base powers.
- Explains that `m s^-1` is dimensionally inconsistent with acceleration.
- Gives the corrected unit `m s^-2`.
- Avoids saying that units are optional labels added after the number.
