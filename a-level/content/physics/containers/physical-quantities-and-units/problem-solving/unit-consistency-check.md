# Transfer Problem: Unit Consistency Check

A student writes a measured acceleration as `9.8 m s^-1`.

## Strategy

1. Name the quantity: acceleration.
2. Recall the relationship: acceleration is change in velocity per unit time.
3. Expand the units: velocity has unit `m s^-1`; dividing by time gives `(m s^-1) / s = m s^-2`.
4. Compare the note: `m s^-1` has dimension `L T^-1`, so it is speed units.
5. Correct the record: acceleration should be written as `9.8 m s^-2` if the numerical value is intended to represent gravitational acceleration.

## Rubric anchor

A complete answer must separate the physical quantity from the numerical value, state the correct unit formula, identify why `m s^-1` is dimensionally inconsistent, and give the corrected unit.
