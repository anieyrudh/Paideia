# Problem-Solving Algorithm

Use this when checking a measured quantity, conversion, or formula.

1. Identify the physical quantity being measured or calculated.
2. Write the value with its unit; do not separate the number from the unit.
3. Classify the quantity as base or derived.
4. If it is derived, draw or imagine the dependency chain back to SI base quantities.
5. Expand derived units into base dimensions when the formula is unclear.
6. Check that added or compared quantities have the same dimension.
7. Check that the left and right sides of an equation reduce to the same dimension.
8. Convert units using a ratio equal to one.
9. State the final value with the correct unit and, where relevant, direction.
