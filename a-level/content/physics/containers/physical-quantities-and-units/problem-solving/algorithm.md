# Problem-Solving Algorithm

Use this when checking a measured quantity, conversion, or formula.

1. Identify the physical quantity being measured or calculated.
2. Decide whether the quantity is base or derived.
3. Decide whether direction is part of the quantity's meaning.
4. Write the value with its unit.
5. Expand derived units into base units when the formula is unclear.
6. Check that added, compared, or equated quantities have matching dimensions.
7. Convert units using a ratio equal to one.
8. State the final value with the correct unit.
