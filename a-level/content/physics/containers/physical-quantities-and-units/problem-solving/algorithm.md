# Problem-Solving Algorithm

Use this when checking a measured quantity, conversion, or proposed formula.

1. **Name the physical quantity.** Decide what each symbol is supposed to measure.
2. **Attach the unit to the value.** A number without a unit is not a complete physical measurement.
3. **Expand derived units.** Rewrite `N`, `J`, `Pa`, or `m s^-1` in SI base units when the equation is unclear.
4. **Combine powers.** Multiplication adds base-unit exponents; division subtracts base-unit exponents.
5. **Compare both sides.** Quantities that are added, compared, or equated must have the same dimensions.
6. **Reject mismatches early.** If the unit fingerprints differ, no choice of numerical values can fix the equation as written.
7. **Convert only with ratios equal to one.** Unit conversion changes the numerical value and unit together, not the physical quantity.
8. **State the result.** Include the quantity name, numerical value, unit, and a brief dimensional reason.
