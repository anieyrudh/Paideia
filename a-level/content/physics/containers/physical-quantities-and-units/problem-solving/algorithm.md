# Problem-Solving Algorithm

Use this when checking a measured quantity, conversion, derived unit, or formula.

1. Identify the physical quantity being measured or calculated.
2. Write the value with its unit; do not leave the number detached from the unit.
3. For repeated readings, calculate the best estimate and the spread-based uncertainty.
4. Compare repeated-reading spread with instrument resolution and report a sensible uncertainty.
5. Expand derived units into base units when the formula is unclear.
6. Check that added, averaged, or compared quantities have the same dimension.
7. For multiplication or division, combine units algebraically and add percentage uncertainties where appropriate.
8. Convert units using a ratio equal to one.
9. State the final value with unit and uncertainty to a sensible precision.
