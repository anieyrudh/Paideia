# Problem-Solving Algorithm

Use this when checking a measured quantity, conversion, or proposed formula.

1. Identify the physical quantity on each side of the statement.
2. Write every value with its unit; do not separate the number from the unit.
3. Expand derived units into SI base dimensions when the relationship is unclear.
4. For addition or subtraction, check each term first: only matching dimensions can be combined.
5. For equality, compare the final left-side and right-side dimensions.
6. Check whether the target quantity is scalar or vector; a scalar expression cannot supply missing direction.
7. Convert units using a ratio equal to one.
8. State whether the statement is valid, impossible as written, or dimensionally possible but not proven.
