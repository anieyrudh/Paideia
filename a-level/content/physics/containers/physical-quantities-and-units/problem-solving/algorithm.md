# Problem-Solving Algorithm

Use this when checking a measured quantity, conversion, or proposed formula.

1. Identify the physical quantity being measured or calculated.
2. Write the value with its unit.
3. Classify each quantity as base or derived; note scalar/vector status if direction matters.
4. Expand derived units into SI base units when the formula is unclear.
5. For addition or equality, check that every term has the same base dimensions.
6. If any term has different dimensions, reject the equation as impossible as written.
7. If dimensions match, continue with physics reasoning; dimensional consistency is necessary but not sufficient proof.
8. Convert units using a ratio equal to one.
9. State the final value with the correct unit.
