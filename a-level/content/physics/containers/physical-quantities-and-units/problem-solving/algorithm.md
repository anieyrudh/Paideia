# Problem-Solving Algorithm

Use this when checking a measured quantity, conversion, uncertainty statement,
or formula.

1. **Name the physical quantity.** Decide what is being measured or calculated.
2. **Attach the record.** Write the numerical value with its unit and, for measurements, its uncertainty.
3. **Classify the quantity.** Decide whether it is base or derived, and scalar or vector where the distinction matters.
4. **Expand derived units.** Reduce units to base dimensions when a formula is unclear.
5. **Check dimensional consistency.** Added or compared terms must have the same dimension; multiplied or divided terms create a derived dimension.
6. **Propagate uncertainty with the operation.** Absolute uncertainties carry the same unit as the quantity; percentage uncertainties are dimensionless.
7. **Convert using ratios equal to one.** Change units without changing the physical quantity.
8. **State the final result.** Give the quantity, value, uncertainty if relevant, and unit.
