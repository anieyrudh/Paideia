# Problem-Solving Algorithm

Use this when checking a measured quantity, conversion, formula, or uncertainty statement.

1. Identify the physical quantity being measured or calculated.
2. Write the value with its unit; include uncertainty if the value came from a measurement.
3. Decide whether the quantity is base or derived.
4. Decide whether direction is part of the quantity: scalar if not, vector if yes.
5. Expand derived units into base units when the formula is unclear.
6. Check that added or compared quantities have the same dimension.
7. For multiplication or division of measured values, combine percentage uncertainties.
8. Convert units using a ratio equal to one.
9. State the final value with the correct unit and a sensible uncertainty or precision.
