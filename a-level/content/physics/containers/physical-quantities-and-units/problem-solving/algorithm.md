# Problem-Solving Algorithm

Use this when checking a measured quantity, conversion, or formula.

1. Identify the physical quantity being measured or calculated.
2. Write the value with its unit.
3. Decide whether the quantity is base or derived, and whether direction is relevant.
4. Expand derived units into SI base dimensions when the formula is unclear.
5. For multiplication, add dimension exponents; for division, subtract exponents.
6. For addition, subtraction, comparison, or equality, check that dimensions match.
7. Convert units using a ratio equal to one only after the dimensions are consistent.
8. State the final value with the correct unit, or reject the equation as impossible as written.
