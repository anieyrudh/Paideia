# Problem-Solving Algorithm

Use this when checking a measured quantity, conversion, or proposed equation.

1. Identify the physical quantity being measured or calculated.
2. Write the value with its unit.
3. Decide whether the quantity is scalar or vector in the chosen context.
4. Expand derived units into base dimensions when the formula is unclear.
5. Check that added, subtracted, or equated quantities have the same dimensions.
6. Convert units using a ratio equal to one.
7. State the final value with the correct unit and explain what the unit check can and cannot prove.
