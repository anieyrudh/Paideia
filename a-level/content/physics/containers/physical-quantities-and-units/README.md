# Physical Quantities and Units

This is the product-quality entry container for the first A-Level physics mini
sequence. It establishes quantity/value/unit discipline before scalar-vector
classification and vector resolution.

## Interaction model

The learner opens a prediction-gated **quantity map / dependency graph lab**.
After committing a prediction about the base dimensions of force, they can choose
a target derived quantity, test candidate equations, and see the dependency path
from SI base quantities to the selected derived quantity. The lab highlights
whether the equation lands on the same dimensions as the target and keeps scalar
or vector status visible without turning the UI into an implementation display.

## Surfaces

- `container.yaml` declares the reviewed, sim-worthy container.
- `concept-card.md` gives the first-principles explanation.
- `simulation/` hosts the prediction-gated quantity map lab.
- `concept-map/` links this concept to Scalars and Vectors and Resolving Vectors.
- `problem-solving/` contains the unit consistency algorithm and transfer task.
- `embed/` exposes the standard host API.
- `media/` provides thumbnail and fallback visuals.
