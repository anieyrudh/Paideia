# Physical Quantities and Units

This product slice turns the prerequisite concept into a prediction-gated
quantity map lab. Learners choose a physical quantity, trace its dependency path
back to SI base quantities, and see why units constrain valid equations.

## Interaction model

The simulation is a quantity map / dependency graph lab:

1. Predict which dependency chain reduces the newton to SI base units.
2. Manipulate the focus quantity and optional link labels on a force-directed map.
3. Observe base vs derived classification, scalar vs vector status, and base-unit reduction.
4. Explain why dimension mismatches reveal invalid equations.

## Surfaces

- `container.yaml` declares the reviewed, simulation-worthy container.
- `concept-card.md` gives the first-principles explanation.
- `concept-map/` links this concept to scalar/vector classification and vector resolution.
- `simulation/` contains the prediction-gated quantity dependency map lab.
- `problem-solving/` contains the unit consistency algorithm and transfer task.
- `embed/` exposes the standard host API.
- `media/` provides thumbnail and fallback visuals.
