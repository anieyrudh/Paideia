# Physical Quantities and Units

This container is now a product-quality A-Level physics vertical slice. It
establishes quantity/value/unit discipline through a prediction-gated
dimensional consistency checker before learners move to scalar-vector
classification and vector resolution.

## Interaction model

The chosen interaction model is a **dimensional consistency checker**. Learners
first predict the unit fingerprint of `mass × speed`. Only after committing a
prediction and rationale does the lab reveal whether equation cards pass or fail
the base-unit check.

## Surfaces

- `container.yaml` declares the reviewed, sim-worthy v2 container.
- `concept-card.md` gives the first-principles explanation and lab purpose.
- `simulation/` hosts the prediction-gated dimensional consistency checker.
- `concept-map/` links unit discipline to vector concepts and misconception traps.
- `problem-solving/` contains the unit consistency algorithm and transfer task.
- `embed/` exposes the standard host API.
- `media/` provides thumbnail and fallback visuals.
