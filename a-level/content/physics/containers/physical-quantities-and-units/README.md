# Physical Quantities and Units

This container is a product-quality measurement and uncertainty lab for the
first A-Level physics mini graph. It establishes quantity/value/unit discipline,
then lets learners manipulate repeated readings, instrument resolution, and
travel time to see why uncertainty and dimensional consistency constrain valid
physics equations.

## Interaction model

Measurement and uncertainty lab:

1. Learners commit a prediction about which evidence should set the reported uncertainty.
2. They manipulate two length readings, ruler resolution, and time.
3. The lab reveals the best estimate, absolute uncertainty, derived speed, unit algebra, and a compact dimensional-consistency check.
4. The transfer task asks learners to apply the same reasoning to a speed record.

## Surfaces

- `container.yaml` declares the reviewed, sim-worthy v2 container.
- `concept-card.md` gives the first-principles explanation.
- `simulation/` hosts the prediction-gated measurement and uncertainty lab.
- `concept-map/` links measurement discipline to Scalars and Vectors and Resolving Vectors.
- `problem-solving/` contains the measurement/unit consistency algorithm and transfer task.
- `embed/` exposes the standard host API.
- `media/` provides thumbnail and fallback visuals.
