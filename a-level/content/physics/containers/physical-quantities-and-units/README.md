# Physical Quantities and Units

This product-quality A-Level Physics container establishes quantity/value/unit
discipline before scalar-vector classification, vector resolution, and
kinematics.

## Interaction model

The learner-facing simulation is a **dimensional consistency checker**. Learners
first predict which proposed equation units will reject, then unlock an
interactive audit that expands each side into SI base dimensions.

The lab focuses on:

- distinguishing physical quantities from numerical values and units;
- recognising base and derived quantities;
- seeing scalar/vector labels where they are relevant without making them the main task;
- comparing dimensions before trusting an equation;
- explaining why units constrain valid physics equations.
