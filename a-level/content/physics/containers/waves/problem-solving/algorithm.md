# Waves Problem-Solving Algorithm

1. Name the position and time where the waves overlap.
2. Find each wave's displacement at that same position and time.
3. Use phase difference to decide whether the second displacement has the same sign, opposite sign, or a partial shift.
4. Add the displacements: `y_resultant = y1 + y2`.
5. Calculate frequency separately if needed: `f = 1 / T`.
6. Check the physical story: constructive interference makes a larger displacement; destructive interference makes a smaller local displacement.

For the noise-cancellation transfer problem, the cancellation is local
destructive interference. The sound wave and anti-noise wave still have
frequency and energy; the displacement at the listener's ear is reduced because
the two displacements have opposite signs.
