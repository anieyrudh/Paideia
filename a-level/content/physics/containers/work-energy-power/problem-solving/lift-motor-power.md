# Transfer Problem: Lift Motor Power

## Prompt

Two motors lift the same load through the same height. Motor A takes 4.0 s and
Motor B takes 10.0 s. Compare the work done and the average power, then explain
why the answers differ.

## Solution Path

1. The load and height are the same, so the force and displacement for lifting
   are the same.
2. The work done is therefore the same for both motors:

   ```text
   W = F s cos(theta)
   ```

   For vertical lifting, the force and displacement are in the same direction,
   so `theta = 0 deg` and `cos(theta) = 1`.

3. Average power depends on time:

   ```text
   P = W / t
   ```

4. Motor A has the larger average power because it transfers the same energy in
   the shorter time.

## Rubric

- Identifies that work is the same because the same load is lifted through the
  same height.
- Uses `W = F s cos(theta)` or an equivalent energy-transfer statement.
- Uses `P = W / t`.
- Explains that shorter time means greater average power for the same work.
