# Hypothesis Testing Mindmap

- Hypotheses
  - \(H_0\): equality claim for the population parameter
  - \(H_1\): direction of evidence
- Standardisation
  - standard error \(SE = \sigma / \sqrt{n}\)
  - z-statistic compares observed gap to standard error
- Decision
  - choose significance level before seeing the result
  - compare z with the critical region
  - translate the p-value comparison into context
- Misconceptions
  - p-value is not \(P(H_0\text{ true})\)
  - rejection is not proof
  - sample size and spread matter, not just the raw difference
- Transfer
  - exam-score claims
  - waiting-time claims
  - manufacturing mean checks
