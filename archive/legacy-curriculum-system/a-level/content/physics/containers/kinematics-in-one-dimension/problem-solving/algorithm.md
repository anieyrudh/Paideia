# Kinematics Problem-Solving Algorithm

1. Choose a positive direction before assigning any signs.
2. List `u`, `v`, `a`, `s`, and `t`; mark the unknown and leave unavailable quantities blank.
3. Check that acceleration is constant for the interval being modelled.
4. Select the constant-acceleration equation that contains only one unknown.
5. Substitute values with signs and SI units.
6. Solve algebraically, then interpret the sign in words.
7. Check against a graph idea: slope for acceleration or area under velocity-time for displacement.

Use:

```text
v = u + at
s = ut + 1/2 at^2
v^2 = u^2 + 2as
s = 1/2(u + v)t
```

The equations are valid only when `a` is constant during the chosen interval.
