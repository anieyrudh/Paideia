# Circular Motion Problem-Solving Algorithm

1. Draw the object at the stated point on the circle and mark the centre.
2. Draw velocity tangent to the path.
3. Draw radial acceleration toward the centre.
4. Identify the real interaction that supplies the inward resultant force.
5. Convert all values to SI units.
6. Calculate radial acceleration with `a_c = v^2 / r`.
7. Calculate inward resultant force with `F_c = m a_c`.
8. Interpret the answer in context: increasing speed has a squared effect, smaller radius increases the demand, and mass changes force but not acceleration.

## Common Checks

- If speed is constant, acceleration may still be non-zero because velocity direction changes.
- Do not add a separate centripetal force beside friction, tension, gravity, or normal contact. Decide which real force or combination of forces is the inward resultant.
- The inward direction changes around the circle, but it always points toward the centre.
