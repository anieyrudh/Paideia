# Problem-Solving Algorithm

Use this procedure whenever a question asks for a combined physical quantity.

1. Name the quantity being combined.
2. Decide whether direction is part of the quantity's meaning.
3. If direction is not part of the meaning, add scalar magnitudes with units.
4. If direction is part of the meaning, choose a vector representation:
   geometric arrows, components, or a scale diagram.
5. Combine components or arrows while preserving direction.
6. Convert the resultant back into the requested magnitude and direction.
7. Check whether the answer is displacement-like or distance-like before
   comparing it with a scalar total.

For perpendicular displacements, the default formula is:

```text
|R| = sqrt(A^2 + B^2)
```

For two vectors with angle theta between them, the more general relation is:

```text
|R| = sqrt(A^2 + B^2 + 2AB cos(theta))
```
