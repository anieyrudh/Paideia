# Transfer Problem: Drone Velocity Components

A drone flies at `14 m/s` on a heading `35 degrees` north of east.

## Expected Reasoning

The eastward component is:

```text
vx = 14 cos 35 degrees = 11.5 m/s
```

The northward component is:

```text
vy = 14 sin 35 degrees = 8.0 m/s
```

This is the same vector-resolution idea as the force example because the
original vector is replaced by perpendicular components along chosen axes. The
unit changes to `m/s`, but the angle reference still decides adjacent and
opposite sides.

## Rubric

- Draws or names the east and north axes.
- Identifies eastward as adjacent because the angle is measured north of east.
- Uses cosine for the eastward component and sine for the northward component.
- Keeps `m/s` as the unit for both components.
- Explains that the component idea transfers from force to velocity.
