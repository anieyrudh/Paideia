# Problem-Solving Algorithm

Use this when a vector must be replaced by components.

1. Draw the vector.
2. Mark the angle and the axis it is measured from.
3. Choose perpendicular axes.
4. Identify which component is adjacent to the marked angle.
5. Use cosine for the adjacent component and sine for the opposite component.
6. Keep the same unit on both components.
7. Check that recombining the components would recover the original vector.
