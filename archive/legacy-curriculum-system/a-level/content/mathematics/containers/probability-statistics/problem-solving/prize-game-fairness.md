# Transfer Problem: Prize Game Fairness

A school fundraiser game awards 0 points, 4 points, or a high-score prize. The organisers claim that a new version is more generous because the high-score prize is larger.

Use the same steps as the simulation:

1. Define X as the points from one play.
2. Convert the outcome weights into probabilities.
3. Compute E(X) and Var(X).
4. Treat the old expected score as the null mean.
5. Use the observed sample mean and sample size to compute the z-score.
6. Decide whether the sample gives enough evidence that the mean score changed.

Rubric anchor:

- Full credit requires a valid probability distribution, correct substitution into E(X), a variance or standard deviation used in the standard error, and a conclusion that mentions the fundraiser context.
- Partial credit is available for correct expected value work even if the hypothesis-test decision is incomplete.
