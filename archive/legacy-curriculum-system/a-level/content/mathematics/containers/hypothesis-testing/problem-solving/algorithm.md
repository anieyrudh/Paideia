# Hypothesis Test Algorithm

1. Name the parameter and write \(H_0\) as an equality claim.
2. Choose \(H_1\) from the wording: greater than, less than, or different from.
3. Record the significance level before comparing results.
4. Compute the standard error in context units.
5. Standardise the sample mean with \(z = (\bar{x} - \mu_0) / SE\).
6. Compare the statistic with the critical region for the tail and significance level.
7. State the decision and interpret it without claiming that the p-value is \(P(H_0)\).

## Decision Wording

- If the statistic is in the critical region: "Reject \(H_0\). There is evidence at the stated level that ..."
- If the statistic is not in the critical region: "Do not reject \(H_0\). The sample does not provide sufficient evidence at the stated level that ..."

Always finish with the context, units, and parameter being tested.
