# Transfer Problem: Studio Facade Retrofit

A studio facade is redesigned after a daylight review. The opening ratio must increase from `0.45` to `0.70`. The existing bay uses a moment frame and carries a lateral demand of `30 kN`.

## Task

Decide whether the structural system should remain a moment frame or change to a diagonal brace. Explain the tradeoff to a non-engineer client.

## Expected Reasoning

1. Calculate the daylight proxy for the larger opening.
2. Calculate the lateral capacity proxy for the moment frame.
3. Calculate the residual lateral force.
4. Repeat for a diagonal brace.
5. Recommend the option that preserves useful daylight while giving the lateral load a clearer path.

## Rubric

- Full credit: separates daylight from lateral resistance, shows both formulas with substituted values, and explains the client-facing tradeoff in plain language.
- Partial credit: identifies that larger openings affect structure but does not quantify the residual force.
- Misconception flag: says the larger opening is automatically better because it admits more light.
