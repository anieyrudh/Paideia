## What this teaches

Tune one structural bay to see how bracing, window opening, and lateral load compete between a clear force path and useful daylight.

A building bay has to do two jobs at once. It must let useful light into the room, and it must give forces a continuous path to the ground. A larger opening can improve daylight, but it can also remove wall area, bracing, or stiffness that helps carry lateral load. The design question is not "more glass or more structure"; it is "what path carries the load, and how much opening can remain once that path is clear?"
