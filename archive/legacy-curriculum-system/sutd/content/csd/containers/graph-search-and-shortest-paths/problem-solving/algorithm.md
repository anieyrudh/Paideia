# Transfer Problem: Campus Shuttle Routing

Given a directed non-negative weighted graph with 7 stops, determine:
1. BFS order from stop A.
2. DFS order from stop A (alphabetical neighbor ordering).
3. Dijkstra minimum cost from A to G.

Rubric:
- 2 pts correct BFS trace.
- 2 pts correct DFS trace.
- 3 pts correct Dijkstra arithmetic with substituted values and signs.
- 3 pts interpretation of why answers differ.
