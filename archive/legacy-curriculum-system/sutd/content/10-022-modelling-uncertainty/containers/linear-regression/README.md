## What this teaches

Fit and interpret a least-squares line through a noisy data cloud without overstating causation.

Linear regression fits a straight-line model `y_hat = mx + b` to paired data. The least-squares fit chooses `m` and `b` to minimise the sum of squared vertical residuals, not to pass through every point.
