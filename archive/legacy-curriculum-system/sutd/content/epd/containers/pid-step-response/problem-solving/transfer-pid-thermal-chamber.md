# Transfer problem: thermal chamber controller

A thermal chamber uses the same control structure but different physical context. You need a response that reaches setpoint quickly without large overshoot to avoid damaging samples.

## Task

Given three candidate gain sets, pick one and justify your decision using overshoot, settling time, and steady-state error.

## Rubric (5 marks)

1. Correctly identifies the safest overshoot region for this context (1).
2. Uses at least two quantitative metrics in justification (2).
3. Explains one tradeoff explicitly (1).
4. Suggests one follow-up tuning move if constraints tighten (1).
