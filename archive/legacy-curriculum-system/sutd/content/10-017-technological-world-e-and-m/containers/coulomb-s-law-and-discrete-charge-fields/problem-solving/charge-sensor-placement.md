# Charge Sensor Placement

A sensor probe with charge `+8 nC` is placed `18 cm` from a `-0.7 microC` source charge.

1. Compute the field magnitude at the sensor.
2. State the field direction relative to the source.
3. Compute the force magnitude on the sensor.
4. Explain how the force direction would change if the sensor charge were `-8 nC`.

The same field is sampled in both cases; only the force direction changes with the sign of the probe charge.
