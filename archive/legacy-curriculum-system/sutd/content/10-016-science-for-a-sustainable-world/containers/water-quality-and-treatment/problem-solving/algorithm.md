# Problem-Solving Algorithm

1. Identify raw turbidity, removal fraction, disinfectant dose, contact time,
   pH, and flow condition.
2. Compute finished turbidity with \(C_{out}=C_{in}(1-r)\).
3. Compute disinfectant exposure with \(CT=C_{chlorine}t\).
4. Check whether the finished pH is inside the operating band.
5. Read the flow evidence to decide whether the filter condition is plausible.
6. Release only if physical clarity, disinfection evidence, and chemistry band
   all pass the screen.
