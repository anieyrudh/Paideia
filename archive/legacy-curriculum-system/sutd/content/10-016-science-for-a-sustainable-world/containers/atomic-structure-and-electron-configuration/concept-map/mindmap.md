# Mindmap

- Atomic structure
  - Atomic number
    - counts protons
    - equals electron count for neutral atoms
  - Electron shells
    - first shell holds 2
    - second shell holds 8 in this first-year model
  - Electron configuration
    - subshell notation such as `1s2 2s2 2p2`
    - shell summary such as `2, 4`
  - Valence electrons
    - outer-shell electrons
    - connect to ions and bonding
