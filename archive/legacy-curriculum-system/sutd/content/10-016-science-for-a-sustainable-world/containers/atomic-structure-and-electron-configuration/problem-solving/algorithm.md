# Algorithm

1. Read the atomic number `Z`.
2. For a neutral atom, set total electrons equal to `Z`.
3. Fill lower-energy subshells first: `1s`, `2s`, `2p`, `3s`, `3p`, then continue as needed.
4. Group the filled subshells by principal shell.
5. Identify the outermost occupied shell.
6. Use the outer-shell electron count as the valence-electron count.
7. Interpret the valence count in context: one outer electron suggests easy loss, seven suggests a tendency to gain one, and full outer shells are comparatively stable.
