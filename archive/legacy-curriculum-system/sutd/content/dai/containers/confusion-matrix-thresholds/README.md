## What this teaches

Tune a classifier threshold and explain how false positives, false negatives, precision, recall, and stakeholder cost move together.

A classifier score is not yet a decision. A threshold turns the score into a positive or negative prediction. Once the threshold is chosen, every case lands in one of four cells: true positive, false positive, true negative, or false negative. The confusion matrix is the accounting table that keeps those cells visible.
