## What this teaches

Balance perpendicular forces by making the resultant force zero in both horizontal and vertical directions.

An object is in equilibrium when all the forces on it cancel. That does not mean there are no forces; it means the horizontal forces sum to zero and the vertical forces sum to zero. If either resultant is non-zero, the object accelerates in that direction.
