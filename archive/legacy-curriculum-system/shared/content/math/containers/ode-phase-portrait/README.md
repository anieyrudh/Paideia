## What this teaches

Classify a two-variable linear ODE by trace, determinant, and discriminant, then test how nearby trajectories move in the phase plane.

A phase portrait shows how a system changes when its current state is a point in the plane. For a two-variable ODE, each point `(x, y)` has an arrow `(x', y')`. An equilibrium is only a point where that arrow is zero. The surrounding arrows still matter: they tell whether a nearby disturbance returns, escapes, spirals, or splits along different directions.
