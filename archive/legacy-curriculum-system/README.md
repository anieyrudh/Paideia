# Legacy Curriculum System Archive

This folder preserves the previous Paideia monorepo experiment:

- A-Level and SUTD curriculum containers;
- shared simulation packages;
- core kernels;
- sim harness tests;
- old GitHub Actions workflows;
- roadmap tables and generated-graph machinery.

The active project has been simplified.

Current Paideia is:

```text
people submit contribution folders -> checks run -> GitHub Pages lists them
```

The archived system is kept for reference only. New contributors should not
start here unless a maintainer explicitly asks them to recover a legacy lesson
or simulation pattern.
