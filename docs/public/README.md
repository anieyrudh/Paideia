# Public Onboarding Docs

This folder holds public-facing onboarding material for Paideia contributors,
especially nontechnical collaborators and Curriculum Field Engineers.

## Source Of Truth

Track accessible source files here, such as HTML or Markdown. Treat PDF, PNG,
and social-card exports as generated artifacts unless a PR explicitly documents
why they need to be committed.

Before publishing generated PDFs or images:

1. Verify the source HTML or Markdown is current.
2. Verify text remains selectable/searchable in the PDF.
3. Verify the first page/cover has no clipped or overlapping text.
4. Link back to the practical contributor workflow in
   [`docs/agent-workflows.md`](../agent-workflows.md).
