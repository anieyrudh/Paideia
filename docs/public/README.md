# Public Onboarding Docs

This folder holds public-facing onboarding material for Paideia contributors:
teachers, students, simulation designers, reviewers, and AI-assisted builders.

## Source Of Truth

Track accessible source files here, such as HTML or Markdown. Treat PDF, PNG,
and social-card exports as generated artifacts unless a PR explicitly documents
why they need to be committed.

Before publishing generated PDFs or images:

1. Verify the source HTML or Markdown is current.
2. Verify text remains selectable/searchable in the PDF.
3. Verify the first page/cover has no clipped or overlapping text.
4. Link back to either the lightweight contribution package flow or the full
   container workflow.

## Current Artifacts

- [`contribution-packages.md`](contribution-packages.md) - lightweight package
  format for standalone lessons, simulations, embeds, and teacher notes.
- [`ai-simulation-prompts.md`](ai-simulation-prompts.md) - copy-paste prompts
  for ChatGPT, Claude, Gemini, Codex, and Claude Code contributors.
- [`cfe-onboarding.html`](cfe-onboarding.html) - canonical public brief for
  Curriculum Field Engineers and Concepts For Everyone contributors.
