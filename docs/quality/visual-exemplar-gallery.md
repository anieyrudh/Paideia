# Visual Exemplar Gallery

Use these patterns when designing a new simulation reveal. Pick the pattern that
matches the concept instead of defaulting to metric cards.

| Pattern | Best for | Required reveal evidence |
| --- | --- | --- |
| Vector geometry | Forces, fields, transformations, eigenvectors | Coordinate grid, original vector, transformed/result vector, coloured basis or component legend |
| Response chart | Control, circuits, dynamics, filters | Time or frequency axis, plotted response curve, target/reference line, readout cards |
| Graph traversal | Algorithms, networks, routing | Nodes and weighted edges, highlighted frontier/visited/path, step or mode readout |
| Probability distribution | Bayes, random variables, inference | Prior/posterior bars, distribution curve or mass plot, shaded event region, probability legend |
| Biological pathway | Cell signalling, gene expression, immune response | State/pathway diagram, node activation levels, flow arrows, threshold or dose marker |
| Systems feedback loop | PID, energy systems, operations | Input → process → output loop, feedback arrow, gain/loss readouts, formula card |

## Quality Notes

- Put the visual inside the live observation region and keep it visible from first load.
- Keep labels student-facing. Do not show package names, file paths, queue IDs,
  or generated registry language.
- Use colour to connect the formula legend to the diagram or chart.
- Keep static images as supporting media only. The primary reveal should be
  generated from the current model state.
