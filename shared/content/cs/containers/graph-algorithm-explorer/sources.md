# Sources

- Cormen, T. H., Leiserson, C. E., Rivest, R. L., and Stein, C. *Introduction to Algorithms*, 4th edition, Chapters 20 and 22. MIT Press, 2022.
- Skiena, S. S. *The Algorithm Design Manual*, 3rd edition, Chapter 7: Graph Algorithms. Springer, 2020.
- Dijkstra, E. W. "A note on two problems in connexion with graphs." *Numerische Mathematik* 1, 269-271, 1959.

These sources support the clean-room explanation of traversal invariants, non-negative weighted shortest paths, and the distinction between graph representation and visual layout. No source code from external algorithm visualisers was viewed or copied.
