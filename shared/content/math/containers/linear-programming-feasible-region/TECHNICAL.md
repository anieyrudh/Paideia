## Kernel Boundaries

The simulation does not solve the feasible polygon locally. It passes the
declared constraints to `core/optimization.linearFeasibleRegion()` and passes
the returned region to `core/optimization.optimizeLinearObjective()`. The UI
only formats substitutions, draws the returned vertices, and labels the
selected point.

`core/plotting.PlotFrame` owns the plot coordinate surface. The local helper
maps kernel points to SVG coordinates for overlays, but does not alter the
kernel vertices or re-sort the polygon.

`core/ui-sim` provides all sliders. There are no native range inputs in the
container sim. `core/prediction-gate` owns reveal state; the sim does not read
or write its localStorage key.
