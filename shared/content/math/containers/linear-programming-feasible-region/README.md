## What this teaches

Build the feasible polygon from two-variable inequalities, then sweep a linear objective line to find the best corner.

A two-variable linear programme turns limits into inequalities. Each inequality keeps one side of a boundary line. The feasible region is the overlap of all those allowed half-planes, including non-negativity limits such as `x >= 0` and `y >= 0` when the quantities are production amounts.
