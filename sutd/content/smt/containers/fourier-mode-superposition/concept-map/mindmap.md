# Mindmap

- Fourier mode superposition
  - Prerequisites
    - Oscillations: modes repeat in space.
    - Eigenvectors: basis directions can be scaled independently.
    - Linear stability: modal coordinates simplify linear evolution.
  - Core ideas
    - Basis mode: `sin(n pi x / L)`.
    - Coefficient: signed projection of target shape onto a basis mode.
    - Reconstruction: sum of selected modal contributions.
    - Error: root-mean-square residual between target and reconstruction.
  - Misconceptions
    - One mode must explain every shape.
    - Coefficients are arbitrary visual sliders.
  - Transfers
    - Heat-equation initial temperature.
    - Signal filtering.
    - PDE separation of variables.
