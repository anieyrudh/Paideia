# Transfer Rubric: Canopy Wind-Load Check

| Criterion | Evidence of success |
| --- | --- |
| Load path | Sideways and gravity loads are traced to named supports without disappearing. |
| Brace calculation | Uses `F_b = H / cos(theta)` with substituted values and kN units. |
| Reaction calculation | Uses `Delta R = Hh / L` and reports both vertical reactions. |
| Interpretation | Identifies whether the canopy has clear path, brace overstress, or uplift risk. |
| Communication | Explains the result in architectural terms without hiding the force reasoning. |
