# Misconception Audit

## Equal Accuracy Means Equal Impact

This misconception appears when learners compare only the percentage of correct
decisions. The simulation surfaces it by keeping accuracy close enough to be
tempting while the recall and weighted harm gaps show a deployment risk.

## One Global Threshold Is Always Fairest

This misconception appears when learners treat identical treatment as identical
impact. The simulation tests it by letting Group B's threshold move separately
and requiring the learner to explain which group cells changed.

## Threshold Adjustments Automatically Solve Fairness

This misconception appears when learners move a threshold until one metric looks
better. The transfer problem requires a policy explanation that names the
stakeholder burden created by false positives and false negatives.
