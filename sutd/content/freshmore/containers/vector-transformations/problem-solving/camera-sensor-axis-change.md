# Transfer Problem — Camera Sensor Axis Change

## Prompt
Given T = [[0,-1],[1,0]] and v=(3,1), compute T(v) and check whether direction d=(1,1) is invariant up to scale.

## Rubric
- Correct transformed vector using substitution and signs.
- Correct invariant-direction test by checking whether T(d)=k d for some scalar k.
- Clear interpretation in words (rotation changes direction so d is not invariant).
