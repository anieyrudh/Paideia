## What this teaches

Find the long-run state mix of a two-state stochastic system from its transition matrix.

A Markov chain describes a system whose next state depends on its current state and a transition rule. In ESD, that rule can describe a queue that is smooth or congested, a machine that is up or down, or a customer who is active or dormant. The steady state answers a long-run planning question: if the same transition pattern keeps repeating, what fraction of time should the system spend in each state?
