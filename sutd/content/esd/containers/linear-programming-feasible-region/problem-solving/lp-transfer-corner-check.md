# Transfer Problem — Production Mix

A microfactory makes product A and B. Let x and y be batches/day.
Maximize Z = 4x + 3y subject to x + y <= 12, x + 2y <= 14, x >= 0, y >= 0.

## Rubric
1. Lists all feasible corner points correctly.
2. Substitutes each point into objective with arithmetic signs shown.
3. States the maximum value and interprets it in context.
