# Algorithm

1. Write the vector field as `F=<P,Q>`.
2. Compute `dP/dx` and `dQ/dy`, then add them for divergence.
3. Compute `dQ/dx` and `dP/dy`, then subtract them for 2D curl.
4. Interpret positive divergence as local source behaviour and negative divergence as sink behaviour.
5. Interpret nonzero curl as signed local rotational tendency.
