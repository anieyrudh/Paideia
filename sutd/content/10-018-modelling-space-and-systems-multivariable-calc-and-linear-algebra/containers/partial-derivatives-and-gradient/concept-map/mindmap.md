# Mindmap

- Partial derivatives and gradient
  - Inputs
    - point \((x_0,y_0)\)
    - scalar surface \(f(x,y)\)
    - test direction \(\mathbf u\)
  - Local rates
    - \(f_x\): x-axis rate with y fixed
    - \(f_y\): y-axis rate with x fixed
    - \(\nabla f=\langle f_x,f_y\rangle\)
  - Visual model
    - contour lines are constant height
    - gradient crosses contours
    - tangent direction has zero first-order change
  - Transfer
    - optimization sensitivity
    - temperature and concentration surfaces
    - vector calculus operators
