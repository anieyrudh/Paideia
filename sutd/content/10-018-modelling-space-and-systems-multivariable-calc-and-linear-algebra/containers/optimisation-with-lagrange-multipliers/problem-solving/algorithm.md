# Problem-Solving Algorithm

1. Write the objective \(f(x,y)\) and constraint \(g(x,y)=c\).
2. Compute \(\nabla f\) and \(\nabla g\).
3. Set up the Lagrange condition \(\nabla f=\lambda\nabla g\) together with
   the constraint equation.
4. Solve the resulting system for \(x\), \(y\), and \(\lambda\).
5. Check candidate points and any boundary cases required by the domain.
6. Interpret \(\lambda\) as sensitivity to the constraint level, not as the
   objective value.
